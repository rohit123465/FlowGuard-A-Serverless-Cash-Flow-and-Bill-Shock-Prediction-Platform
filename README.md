# SafeSpend

SafeSpend helps people with irregular income understand how much they can
safely spend without missing upcoming bills.

## Target user

Freelancers, contractors, students, gig workers, and people with variable income.

## Main problem

Traditional expense trackers explain past spending but do not show whether
the user can afford upcoming commitments.

## MVP

- Record current balance
- Add expected income
- Add upcoming bills
- Add, edit, and delete expenses
- Calculate safe-to-spend
- Display a projected balance timeline
- Warn about predicted shortfalls
